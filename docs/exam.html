Exam information

Author

Mattias Villani

Exam format

  • The exam is for a maximum of 5 hours.

  • The exam is both traditional pen and paper (approximately 25% of the exam) and computer-based with some light coding to solve Bayesian problems (75% of the exam).

In the exam room

  • There will be calculators available in the exam room of this type. You cannot bring your own calculator, according to new department rules.

  • You will have access to a computer running R. No Python!

  • The exam computers use a safe browser called SEB (Safe Exam Browser). You need to follow these instructions (also available in the exam rooms) in order for getting the digital exam material and also for eventually handing in the digital part of the exam.

ImportantAnonymous code needed!

Have your anonymous code available. If you do not have your anonymous code with you, the code will be given to you by the exam hosts. You need the anonymous code to download digital material but you can start and use R without a code.

  • Your computer will have:

    • the exam and formula sheet in pdf format

    • a quarto file exam_template.qmd (here is an example of the quarto file along with a dataset and the file compiled to pdf) which

      • installs the needed/allowed packages for the exam

      • loads the datasets for each problem

      • runs other code supplied with the problem.

      You fill in the answers in the quarto file, compile to pdf (preset in the document) and at the end of the exam submit both the pdf and, optionally, the qmd file. The qmd file is not graded, but may be used in certain cases when the pdf did not compile.

      Important

      Place all files in the Downloads folder on your computer. This is the only folder from where you can submit your answers for the exam.

      Compile the exam_template.qmd file at the beginning of the exam and ask for help if the file does not compile to pdf (it can take a few minutes the first time, so read the exam or solve the math problem while you wait).

    • an R script with the same commands as in the above mentioned quarto file exam_template.qmd file for loading packages, datasets etc. This file is not needed, but may be useful depending on your coding style. The script file will be named BLExamYYYYMMDD.R where YYYYMMDD is the date of the exam. Click on the “>R script” below to see an example of this file.

# The skew normal density function
dskewnormal <- function(y, alpha = 0, log = FALSE){
  if (log == FALSE){
    return(2*dnorm(y)*pnorm(alpha*y))}
  else{
    return(log(2) + dnorm(y, log = TRUE) + 
             pnorm(alpha*y, log.p = TRUE))
  }
}

NoteStan

The exam will not use Stan since the IT department cannot yet guarantee a stable smooth use in the exam rooms.

ImportantR packages

You are only allowed to use the R packages loaded from the Rscript BLExamYYYYMMDD.R available at the exam.

Uploaded Assignment solutions

  • Your report for the assignment parts should be uploaded some days before the exam (exact dates will be announced on Canvas, well before each exam).

  • The report should be uploaded in pdf format at http://gauss.stat.su.se/tenta/. The upload button for this course will be available roughly a week before the exam.

  • The uploaded report can be your own individual version of the group report:

    • Each student is allowed to polish on the report as much as they want before submitting.

    • The questions in the assignments can be included in the report.

    • The report can contain code than you can copy and paste into your exam solutions.

ImportantVery important!
  • You are not allowed to write things in the report that is unrelated to the assignment. That is, you cannot sneak in material not related to the assignment, such as which prior is conjugate to which likelihood, for models that are not part of the assignment. I will personally check the submitted reports and also run them through an AI. I will write on Canvas when I have checked all reports and if you did not get a canvas message about any problems, then all is OK with your uploaded report and I have not found any cheating. You can upload the two parts as separate pdf files. The upload page allows for multiple file uploads, but you can also upload a zip file.
